# تحلیلگر متن فارسی
ابزاری ساده و کارآمد برای تحلیل متن فارسی و دریافت آمار مفید از محتوای آن.
## ویژگی‌ها
- شمارش کلمات، کاراکترها و حروف
- شمارش جملات
- محاسبه فراوانی کاراکترها
- محاسبه فراوانی کلمات
- نمایش کلمات پرتکرار
## نصب و اجرا
این پروژه نیاز به نصب اضافی ندارد و با زبان پایه اجرا می‌شود.
python main.py --text "متن فارسی خود را اینجا بنویسید"
## استفاده
- از `--text` برای ورود متن به صورت مستقیم
- از `--file` برای خواندن متن از فایل
- از `--stdin` برای خواندن متن از ورودی استاندارد
- از `--top` برای تعیین تعداد کلمات پرتکرار
- از `--output` برای ذخیره نتیجه در فایل
## مثال
python main.py --text "سلام دنیا. امیدوارم روز خوبی داشته باشی." --top 5
